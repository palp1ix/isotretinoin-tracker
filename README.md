# Мой курс — трекер изотретиноина

Офлайн-приложение без сервера и внешних зависимостей. Публикуется из `main` на существующем GitHub Pages: https://palp1ix.github.io/isotretinoin-tracker/.

## Версия 5.0.0

Строгий интерфейс с прямыми углами, светлой и тёмной темами, общим обзором курса, активностью за неделю и адаптивной компоновкой. Версия показана в настройках.

### Совместимость с записями

- Основной ключ остаётся `my-course-data-v1`, формат данных — `version: 1`.
- PDF остаются в IndexedDB `isotretinoin-files-v1`, хранилище `pdfs`; идентификаторы вложений сохраняются.
- Перед первым сохранением v5 исходный JSON копируется в `my-course-data-before-v5`. Это локальная страховочная копия, не замена экспорту JSON с PDF.
- При ошибке чтения локальных данных сохранение блокируется. Ошибка записи не заменяет сохранённое состояние и не удаляет прежние PDF при импорте.
- Обновление очищает только старые статические кэши приложения. Адрес сайта, scope и start_url сохранены.
- Для обновления установленного приложения откройте его с интернетом, затем закройте и откройте повторно. Не требуется переустанавливать приложение или очищать данные браузера.

### Расчёты

- Прогресс: сумма записанных доз / заданная пользователем цель, до 100%. Остаток не бывает отрицательным.
- Мг/кг: накопленная доза / вес в килограммах.
- Средняя: последние 14 местных календарных дней, включая сегодняшний. В начале курса — число прошедших дней. Дни без записей считаются как 0 мг. Период начинается с даты старта или более ранней записи, если она существует.
- Прогноз достижения цели: оставшиеся мг / средняя, округление дней вверх. Это арифметическая оценка при сохранении текущего темпа, а не дата окончания лечения.
- Запас: все купленные с начала курса пачки × капсул в пачке × мг в капсуле − записанные мг. Продолжительность запаса использует ту же среднюю, что и прогноз курса. Количество пачек к покупке считается даже без приёмов.
- Будущие записи сохраняются в истории, но не учитываются в текущем прогрессе, расходе и прогнозе.
- Длительность курса считается по календарным датам, включая первый день, без зависимости от времени суток или перехода на летнее время.
- График истории показывает 14 календарных дней с нулевыми днями; дневная доза — левая шкала, накопленная — правая.
- Ориентир 20/40 рассчитывается от последней записи 20 или 40 мг с учётом количества календарных дней. При отсутствии такой записи приложение не выбирает дозу.

Личный ориентир жиров — отметка в журнале, а не оценка усвоения. Приём препарата определяется инструкцией и назначением врача: [NHS](https://www.nhs.uk/medicines/isotretinoin-roaccutane/).

## Локальный запуск

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Данные этого адреса отделены от данных установленного приложения на GitHub Pages.

## Следующий выпуск

Поднимите `CACHE_VERSION` и `RELEASE` в `sw.js`, суффиксы `?v=` в `index.html`, `app.js`, `ui.js` и видимую версию в настройках. Service worker сначала скачивает всю оболочку, затем активирует её. Если пользователь заполняет форму, перезагрузка откладывается до сохранения и выхода из формы.
